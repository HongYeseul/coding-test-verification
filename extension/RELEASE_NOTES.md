보고 있는 화면을 한 번에 스터디 인증으로 남기는 크롬 확장입니다.

## 0.2.13에서 바뀐 것

- 한 문제를 저장소에 올리고 1분 안에 다음 문제를 올리면 ‘그 사이 저장소가 바뀌어 올리지
  못했습니다’로 실패하던 것을 고쳤습니다. 브라우저가 GitHub의 옛 응답을 1분 동안 다시 써서
  방금 올린 커밋을 모르고 있었습니다

저장소에는 공개 저장소에 쓰는 권한으로 올립니다. 모든 공개 저장소에 해당하는 권한이라
비공개 저장소는 고를 수 없습니다. 토큰은 이 확장에만 두고 서버로 보내지 않습니다. README와
커밋에는 문제 설명을 옮기지 않습니다.

LeetCode에는 요청을 하나도 더 보내지 않습니다. 사용자가 누른 제출 한 건이 오가는 것만 보고,
문제 설명·에디토리얼·다른 사람의 풀이는 읽지 않습니다.

## 설치

1. 아래 **dojang-extension zip**을 받아 압축을 풉니다.
2. 크롬에서 `chrome://extensions`을 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**로 압축을 푼 `dojang-extension` 폴더를 고릅니다.

주소나 키를 입력할 게 없습니다. 도장 아이콘을 눌러 GitHub로 한 번 로그인하면 됩니다.
계정은 웹에서 쓰는 것과 같습니다.

## 쓰는 법

- **아이콘을 눌러** 보고 있는 화면을 캡처해 남깁니다.
- **프로그래머스·NeetCode·LeetCode에서 정답이 나오면** 오른쪽 위에 카드가 저절로 뜹니다.
  도장 찍기를 누르면 제출한 코드가 그대로 기록됩니다.
- **카드의 저장소 줄에서 GitHub 저장소를 연결해 두면** 카드로 찍은 풀이가 그 저장소에도 올라갑니다.

## 무엇을 읽나

아이콘을 눌렀을 때 보이는 탭의 화면과 주소, 정답 감지에 쓰는 **채점 결과와 본인이 제출한
코드**, 그 코드의 언어, 그리고 문제의 **번호·제목·난이도**뿐입니다. 언어·난이도·채점 결과는
저장소에 올릴 파일 이름과 커밋 메시지에만 씁니다. 문제 설명·힌트·모범답안은 읽지 않습니다.

## 알아두실 것

- 웹스토어 등록 전이라 자동 갱신이 되지 않습니다. 새 버전은 다시 받아 교체해주세요.
- 교체하기 전부터 열려 있던 NeetCode 탭은 새로고침해야 언어와 통과한 테스트 수를 알아냅니다.
  그 전에 올리면 `solution.txt`로 올라가고 커밋 메시지에 통과 수가 빠집니다.
- 팝업의 ‘연결 끊기’는 확장이 가진 저장소 토큰을 버립니다. GitHub 쪽 권한까지 거두려면 GitHub 설정의
  [Authorized OAuth Apps](https://github.com/settings/applications)에서 지웁니다.
- 사이트 화면이 바뀌면 카드가 안 뜰 수 있습니다. 그때도 아이콘을 눌러 캡처로 남기는
  방식은 그대로 동작합니다.
- NeetCode·LeetCode는 제출에 로그인이 필요합니다. 로그인하지 않으면 카드도 뜨지 않습니다.
- LeetCode 대회 문제에서는 카드가 뜨지 않습니다. 대회 중에는 풀이를 공개하면 안 됩니다.
- 백준은 채점 서비스가 멈춰 있어 대상에서 빠져 있습니다.

지난 버전은 [릴리스 목록](https://github.com/HongYeseul/coding-test-verification/releases)에서 봅니다.
