보고 있는 화면을 한 번에 스터디 인증으로 남기는 크롬 확장입니다.

## 0.2.8에서 바뀐 것

- **도장을 찍으면 풀이를 내 GitHub 저장소에도 올릴 수 있습니다.** 팝업 아래
  ‘GitHub 저장소’에서 연결하고 올릴 저장소를 고르면, 프로그래머스·NeetCode 카드로 도장을
  찍을 때 코드와 README가 커밋 하나로 올라갑니다. 누르는 것은 여전히 도장 찍기 하나입니다
- 한 문제가 한 폴더입니다. 예: `프로그래머스/42576. 완주하지 못한 선수/solution.py`
- README에는 제목·플랫폼·문제 링크·태그만 적습니다. 문제 설명은 플랫폼 콘텐츠라 올리지 않습니다
- 올리다 실패해도 도장은 남고, 결과 카드에서 다시 올릴 수 있습니다

연결하면 GitHub가 **공개 저장소에 쓰는 권한**을 한 번 더 묻습니다. 저장소 하나로 좁힐 수
없는 권한이라 모든 공개 저장소에 해당하고, 그래서 비공개 저장소는 고를 수 없습니다. 토큰은
이 확장에만 두고 서버로 보내지 않습니다. 연결하지 않으면 지금과 똑같이 동작합니다.

LeetCode는 이용약관이 자동화를 금지해 넣지 않았습니다. 아이콘을 눌러 화면으로 남기는
방식은 거기서도 그대로 됩니다.

## 설치

1. 아래 **dojang-extension zip**을 받아 압축을 풉니다.
2. 크롬에서 `chrome://extensions`을 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**로 압축을 푼 `dojang-extension` 폴더를 고릅니다.

주소나 키를 입력할 게 없습니다. 도장 아이콘을 눌러 GitHub로 한 번 연결하면 됩니다.
계정은 웹에서 쓰는 것과 같습니다.

## 쓰는 법

- **아이콘을 눌러** 보고 있는 화면을 캡처해 남깁니다.
- **프로그래머스·NeetCode에서 정답이 나오면** 오른쪽 위에 카드가 저절로 뜹니다.
  도장 찍기를 누르면 제출한 코드가 그대로 기록됩니다.
- **GitHub 저장소를 연결해 두면** 카드로 찍은 풀이가 그 저장소에도 올라갑니다.

## 무엇을 읽나

아이콘을 눌렀을 때 보이는 탭의 화면과 주소, 그리고 정답 감지에 쓰는 **채점 결과와
본인이 제출한 코드**, 그 코드의 언어뿐입니다. 언어는 저장소에 올릴 파일 확장자를 정하는
데만 씁니다. 문제 설명·힌트·모범답안은 읽지 않습니다.

## 알아두실 것

- 웹스토어 등록 전이라 자동 갱신이 되지 않습니다. 새 버전은 다시 받아 교체해주세요.
- 교체하기 전부터 열려 있던 NeetCode 탭은 새로고침해야 언어를 알아냅니다. 그 전에 올리면
  `solution.txt`로 올라갑니다.
- ‘저장소 연결 끊기’는 확장이 가진 토큰을 버립니다. GitHub 쪽 권한까지 거두려면 GitHub 설정의
  [Authorized OAuth Apps](https://github.com/settings/applications)에서 지웁니다.
- 사이트 화면이 바뀌면 카드가 안 뜰 수 있습니다. 그때도 아이콘을 눌러 캡처로 남기는
  방식은 그대로 동작합니다.
- NeetCode는 제출에 로그인이 필요합니다. 로그인하지 않으면 카드도 뜨지 않습니다.
- 백준은 채점 서비스가 멈춰 있어 대상에서 빠져 있습니다.

지난 버전은 [릴리스 목록](https://github.com/HongYeseul/coding-test-verification/releases)에서 봅니다.
