## 0.3.0

- 정답을 맞히면 선택한 GitHub 저장소에 풀이를 자동으로 올립니다. 도장 찍기 버튼을 누를 필요가 없습니다.
- 팝업에서 GitHub로 로그인하고 공개 저장소를 선택하거나 새로 만들 수 있습니다. 스터디 가입은 필요하지 않습니다.
- Vercel·Supabase DB·Storage에 풀이와 도장 기록을 저장하지 않습니다. Supabase는 GitHub 로그인에만 사용합니다.
- LeetCode 본문을 원문 링크와 함께 README에 올립니다. 예시·제한사항·코드 블록도 함께 옮깁니다.
- 본문을 읽지 못하면 풀이 코드와 기본 README만 올립니다. 힌트·에디토리얼·채점용 테스트케이스는 수집하지 않습니다.
- 여러 탭에서 동시에 제출해도 순서대로 올립니다. 실패한 업로드는 카드에서 다시 시도할 수 있습니다.

LeetCode 본문 재게시를 허용하는 공식 안내는 확인하지 못했습니다. 출처 표기가 게시 허락을 대신하지 않습니다.

## 설치

1. `dojang-extension-v0.3.0.zip`을 받아 **새 폴더에** 압축을 풉니다.
2. 크롬의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. 기존 도장을 설치했다면 설치 폴더를 새 파일로 교체하고 확장의 새로고침을 누릅니다.
4. 처음 설치한다면 **압축해제된 확장 프로그램을 로드합니다**로 `dojang-extension` 폴더를 선택합니다.
5. 도장 아이콘에서 GitHub로 로그인하고 공개 저장소를 선택한 뒤 문제를 제출합니다.

기존과 같은 GitHub 계정·Supabase 인증을 사용합니다. 공개 저장소에 쓰는 권한을 요청하며 비공개 저장소는 지원하지 않습니다.
