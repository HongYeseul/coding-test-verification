지금 보고 있는 화면을 한 번에 스터디 인증으로 남기는 크롬 확장입니다.
앱을 열고 그룹을 찾아 모달을 띄우는 과정을 버튼 하나로 줄입니다.

## 0.1.1에서 바뀐 것

떠 있는 버튼만 눌러도 끝나게 했습니다. 예전에는 연결이 안 돼 있으면 "도장 아이콘을 눌러
GitHub로 연결해주세요"라고 안내만 했는데, 크롬이 확장 아이콘을 퍼즐 메뉴에 숨겨 두는
탓에 그 아이콘을 찾는 일이 숙제가 됐습니다.

- 버튼을 처음 누르면 그 자리에서 GitHub 창이 열립니다.
- 스터디가 하나면 묻지 않고, 여럿이면 버튼 옆에서 고릅니다.

## 설치

1. 아래 **dojang-extension zip** 을 받아 압축을 풉니다.
2. 크롬에서 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드** 를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 압축을 푼 `dojang-extension` 폴더를 고릅니다.

주소나 키를 입력할 게 없습니다. 설치한 뒤 도장 아이콘을 눌러 GitHub로 한 번 연결하면 됩니다.
계정은 웹에서 쓰는 것과 같습니다.

## 쓰는 법

**아이콘을 눌러 화면으로 남기기** — 인증할 화면에서 도장 아이콘을 누르고, 스터디를 고른 뒤
‘지금 화면으로 도장 찍기’를 누릅니다. 보이는 탭을 캡처해 올립니다.

**프로그래머스에서 정답이 나오면** — 채점 결과가 정답이면 오른쪽 위에 버튼이 저절로 뜹니다.
누르면 제출한 코드가 그대로 기록됩니다. 팝업을 열 필요가 없습니다.
어느 스터디에 남길지는 아이콘을 눌러 한 번 골라두면 그걸 씁니다.

## 무엇을 읽나

- 아이콘을 눌렀을 때 **보이는 탭의 화면**과 **탭 주소**
- 프로그래머스에서는 **채점 결과 문구**(버튼을 띄울지 정하는 데만 쓰고 서버로 보내지 않습니다)와
  **본인이 제출한 코드**

문제 설명이나 입출력 예시 같은 플랫폼 콘텐츠는 읽지 않습니다.

## 알아두실 것

- 크롬 웹스토어 등록 전이라 개발자 모드로 설치합니다. 자동 갱신이 되지 않으므로
  새 버전은 다시 받아 같은 방식으로 교체해주세요.
- 프로그래머스 화면이 바뀌면 자동 버튼이 안 뜰 수 있습니다. 그때도 아이콘을 눌러 캡처로
  등록하는 방식은 그대로 동작합니다.
- 백준은 채점 서비스가 멈춰 있어 대상에서 빠져 있습니다.
