# 도장 확장 사용 흐름

프로그래머스·NeetCode에서 정답이 나온 그 자리에서 코딩 테스트 스터디 인증을 끝내는 크롬
확장입니다. 정답 순간에 뜨는 카드에서 **도장 찍기**를 한 번 누르면 스터디에 풀이가 남고, 연결해 둔
GitHub 저장소에도 커밋됩니다.

이 문서는 문제를 푼 순간부터 도장 웹사이트에서 확인하기까지를 화면 순서대로 보여줍니다.

- 확장 받기: [최신 릴리스](https://github.com/HongYeseul/coding-test-verification/releases/latest)의 `dojang-extension-v*.zip`
- 도장 웹사이트: https://coding-test-verification.vercel.app/
- 확장이 어떻게 동작하는지 자세히: [extension/README.md](../extension/README.md)

## 확장 전과 후

| 확장 전 — 웹에서 직접 찍는 창 | 확장 후 — 정답 순간에 뜨는 카드 |
|---|---|
| <img src="screenshots/web-manual.png" width="360" alt="웹에서 직접 도장을 찍는 창"> | <img src="../extension/screenshots/card-input.png" width="360" alt="정답 순간에 뜨는 카드"> |
| 통과 화면을 캡처해 올리고 문제 제목·링크·주제 태그를 적습니다. 코드는 사진 속에만 남고, GitHub 저장소에는 코드 파일을 따로 만들어 커밋합니다. | 문제 제목과 제출한 코드는 확장이 채워 둡니다. 도장 찍기 한 번이면 스터디에 코드 전문이 남고 GitHub 저장소에도 커밋됩니다. |

## 처음 한 번

![도장 웹사이트 첫 화면의 스터디 현황과 릴리스 노트](screenshots/web-landing.png)

1. 도장 웹사이트 첫 화면의 릴리스 노트에서 **받으러 가기**를 누르거나, 최신 릴리스에서 zip을 받아
   압축을 풉니다.
2. 크롬에서 `chrome://extensions`를 열고 **개발자 모드**를 켠 뒤, **압축해제된 확장 프로그램을
   로드합니다**로 푼 폴더를 고릅니다. 크롬 웹스토어 등록 전이라 이렇게 설치합니다.
3. 도장 웹사이트에 GitHub로 로그인해 코딩 테스트 스터디에 들어갑니다. 초대코드로 가입하거나,
   직접 만들 때 **코딩 테스트 스터디**를 켭니다. 카드는 코딩 테스트 스터디에만 찍힙니다.

확장은 처음 도장을 찍을 때 GitHub 로그인 창을 한 번 띄웁니다. 웹과 같은 계정입니다.

## 1. 정답이 나오면 카드가 뜹니다

<img src="../extension/screenshots/card-confetti.png" width="427" alt="정답 순간에 뜨는 카드">

프로그래머스·NeetCode에서 제출한 코드가 정답이면 화면 오른쪽 위에 카드가 뜹니다. 문제 제목과
코드 분량은 확장이 채워 둡니다. 주제 태그는 적어도 되고 비워 둬도 됩니다. **도장 찍기**를 누르면
끝입니다.

정답을 맞혔다고 저절로 찍히지는 않습니다. 무엇을 남길지는 본인이 정합니다.

## 2. 무엇이 남았는지 카드가 보여줍니다

<img src="../extension/screenshots/card-result.png" width="388" alt="도장을 찍은 뒤의 카드">

문제·코드·저장소·태그를 찍기 전과 같은 순서로 보여주고 상태를 덧붙입니다. 상태는 그룹 설정에
따라 **검수 대기**나 **자동 인정**입니다. 카드는 5초 뒤 사라지고, 마우스를 올리면 멈춥니다.

## 3. 도장 웹사이트에 바로 보입니다

아래는 2026년 9월 27일에 운영 중인 사이트를 찍은 화면입니다. 공개 저장소라 다른 멤버의 이름·
이니셜·GitHub 아이디는 흐리게 가렸습니다.

![그룹 화면의 오늘 띠, 도장판, 우리 그룹이 푼 문제](screenshots/web-group.png)

그룹 화면에 들어가면 찍은 도장이 세 곳에 보입니다.

- **오늘 띠**: 오늘 누가 도장을 찍었는지 보여줍니다. 찍은 멤버의 이름 앞에 도장이 붙습니다
- **도장판**: 멤버와 요일로 짠 이번 주 현황표입니다. 오늘 칸에 도장이 찍히고, 하루에 여러 문제를
  풀면 개수가 붙습니다
- **우리 그룹이 푼 문제**: 확장이 채운 문제 링크가 모입니다. 다른 멤버가 같은 문제를 바로 풀어볼
  수 있습니다

<img src="screenshots/web-records.png" width="696" alt="풀이 기록 목록">

**풀이 기록**에는 문제 제목·멤버·주제 태그·등록 시각·상태가 한 줄씩 쌓입니다. 코드로 남긴 풀이는
▤로, 화면으로 남긴 풀이는 캡처 썸네일로 구분됩니다.

![기록 상세 창](screenshots/web-detail.png)

줄을 누르면 확장이 보낸 **코드 전문**이 그대로 보입니다. 통과 화면 사진과 달리 읽고 비교할 수
있어서, 검수자는 여기서 코드를 보고 승인하거나 반려합니다. **프로그래머스에서 풀어보기**로 같은
문제를 바로 열 수도 있습니다.

그룹에 디스코드 알림을 켜 두었으면 도장을 찍을 때 그 채널에도 한 줄 올라갑니다.

## 4. GitHub 저장소에도 올라갑니다

<img src="../extension/screenshots/card-pick.png" width="388" alt="카드 안에서 저장소를 고르는 모습">

카드의 **저장소** 줄에서 한 번 연결하고 저장소를 고르면, 그다음부터는 도장 찍기 한 번에 풀이가
그 저장소에도 커밋됩니다. 고르는 칸 맨 아래에서 새 공개 저장소를 만들 수도 있습니다. 연결하지
않으면 도장만 찍힙니다.

<img src="../extension/screenshots/card-repo.png" width="388" alt="저장소에 올린 뒤의 카드">

한 문제가 한 폴더이고, 코드와 README가 커밋 하나로 들어갑니다. 커밋 메시지 첫 줄에는 플랫폼·
난이도·제목·채점 결과를 담습니다.

```
프로그래머스/42746. 가장 큰 수/solution.kt
프로그래머스/42746. 가장 큰 수/README.md

[프로그래머스 Lv.2] 가장 큰 수 · 64.31ms · 96.4MB
```

README에는 제목·플랫폼·난이도·문제 링크·주제 태그만 적고 **문제 설명은 옮기지 않습니다.** 문제
설명은 플랫폼의 콘텐츠라 확장이 읽지도 않습니다.

위 기록 상세의 풀이가 실제로 올라간 폴더는 [HongYeseul/studyingAlgorithm](https://github.com/HongYeseul/studyingAlgorithm/tree/master/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/42746.%20%EA%B0%80%EC%9E%A5%20%ED%81%B0%20%EC%88%98)에
있습니다. 0.2.8로 올려서 커밋 메시지는 `[프로그래머스] 가장 큰 수`로 짧습니다.

## 5. 다른 사이트에서는 화면으로 찍습니다

<img src="../extension/screenshots/popup-form.png" width="300" alt="확장 아이콘을 누르면 뜨는 창">

카드가 뜨지 않는 곳에서는 확장 아이콘을 눌러 스터디를 고르고 **이 화면으로 도장 찍기**를
누릅니다. 보고 있는 화면이 캡처되어 올라가고, 지원하는 플랫폼 주소면 문제 링크도 채워집니다.
웹사이트의 풀이 기록에는 캡처 썸네일이 붙은 줄로 보입니다.

LeetCode는 이용약관이 자동화를 금지해서 카드를 붙이지 않았습니다. LeetCode에서는 이 방법으로
찍습니다.

## 화면 사진에 대해

확장 카드와 창은 실제 확장의 CSS와 스크립트로 그린 사진이고, 담긴 문제·태그·저장소 이름은
예시입니다. 도장 웹사이트 화면은 운영 중인 사이트를 그대로 찍고 다른 멤버만 가렸습니다.
